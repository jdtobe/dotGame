# DotGame visual directions

Open `design-gallery.html` in a web browser to compare ten paired concepts for
the terminal setup UI and Ebitengine game window.

Each concept uses the same representative content so its spacing, color, board
treatment, and information hierarchy can be compared directly. Use the theme
picker or **Choose this direction** button to record a local selection in the
browser; it does not submit or transmit any data. All ten directions are
intended to remain selectable in the finished application.

The terminal previews deliberately use monospace, cell-based styling that can
be reproduced with ANSI colors and Unicode characters. The game previews use
subtle animation to represent the richer Ebitengine presentation. The finished
game will also offer reduced-motion and animation-off settings.

These are visual mockups rather than application screens. The selected design
will be refined for keyboard use, terminal color support, color-blind safety,
small screens, and real game states during implementation.

## Character concepts

Open `character-gallery.html` to compare ten original vector character options
for the victory celebration. Hover previews a simple dance, and selecting a
card stores the choice only in the browser. Once selected, the character can be
converted into transparent PNG sprite sheets for Ebitengine.

Open `rigged-character-gallery.html` for five production-oriented replacements.
These are authored as genuinely separate head, body, arm, leg, hand, sign, and
accessory groups with explicit pivots—no finished-image cropping. Use the
exploded-layer control to inspect how each character will be composited.

Open `stylized-rig-gallery.html` for ten higher-detail original anime-inspired
rigs. They retain the same production-safe construction while adding cel
shading, expressive eyes, distinct hair silhouettes, richer costumes, props,
highlights, and character-specific palettes.
